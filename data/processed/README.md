# Processed and reported reference data

This folder contains reference tables transcribed from the accessible revised manuscript materials made available in the conversation:

- `ofi_dimension_scores_reported.csv`
- `ofi_sensitivity_reported.csv`
- `reported_illustrative_dea_scores.csv`

The DEA score file contains reported illustrative DEA scores only. The DEA input matrix used to generate those scores was not available in the conversation, so the repository does not independently recompute DEA efficiency scores.
