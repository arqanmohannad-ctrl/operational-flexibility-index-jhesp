# Data sources

## Data used in this repository

This repository uses only a simulated numerical dataset created for methodological demonstration. The data are included in:

```text
data/raw/simulated_hospitals_ofi_data.csv
```

The dataset does not contain real hospital-level, patient-level, personal, confidential, proprietary, or restricted data.

## Data not used

No official empirical data from WHO, World Bank, WHO-EMRO, Ministries of Health, hospitals, or patient records were analyzed in this repository.

## Potential official sources for future empirical work

Future empirical applications may consider official and administrative sources such as:

- World Health Organization Global Health Observatory: https://www.who.int/data/gho
- World Bank Health, Nutrition and Population Statistics: https://databank.worldbank.org/source/health-nutrition-and-population-statistics
- WHO Regional Office for the Eastern Mediterranean: https://www.emro.who.int
- National Ministry of Health statistical reports
- Hospital administrative records
- Hospital finance and costing systems

Use of these sources would require careful assessment of variable definitions, reporting years, missingness, public/private sector boundaries, and country-level comparability.
