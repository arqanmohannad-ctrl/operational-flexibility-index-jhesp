# Limitations

1. **Simulated data only**  
   The repository uses hypothetical data for 15 hospitals. It does not provide empirical evidence about real hospitals or MENA health systems.

2. **No causal inference**  
   The analysis is a numerical illustration. It does not estimate causal effects of operational flexibility on efficiency, cost, patient outcomes, or health-system performance.

3. **No completed external validation**  
   The OFI dimensions and weights have not been validated here through expert panels, Delphi methods, content validity indices, psychometric testing, or hospital-level empirical application.

4. **Weighting assumptions are illustrative**  
   Equal weighting is transparent but not necessarily optimal. Alternative weights are included only as sensitivity scenarios.

5. **Min-max normalization sensitivity**  
   Min-max normalization depends on the range of values in the sample. Outliers can affect all normalized values.

6. **Bed occupancy reference value**  
   The 80% bed-occupancy reference value is used for demonstration. Real applications should justify an optimal range using national standards, empirical distributions, hospital type, or expert-informed thresholds.

7. **DEA scores not independently reproduced**  
   The repository includes reported illustrative DEA scores but does not recompute DEA because the underlying DEA input/output matrix was not available in the conversation materials.

8. **No clinical quality outcomes**  
   The simulated illustration does not include mortality, readmissions, adverse events, safety indicators, patient experience, or other clinical outcomes.

9. **No real cost accounting**  
   The cost-output ratio is simulated and should not be interpreted as a true hospital cost measure.
